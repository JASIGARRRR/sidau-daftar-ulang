SIDAU - Paket siap deploy (situs statis)

Cara deploy paling mudah:
1. Ekstrak folder/ZIP ini ke komputer.
2. Buka https://app.netlify.com/drop
3. Jika ingin menyimpan dan mengelola situs, login/sign up ke Netlify dulu.
4. Seret folder SIDAU_Siap_Deploy ke area drop di Netlify, atau pilih folder tersebut melalui tombol Choose folder.
5. Tunggu sampai deployment selesai.
6. Salin URL yang berakhiran netlify.app dan buka URL itu di tab baru.

Catatan:
- Pastikan index.html berada langsung di dalam folder yang diunggah.
- Ini prototipe front-end; data contoh dan simulasi pembayaran bukan layanan kampus/bank yang nyata.
- Data demo disimpan pada browser/perangkat pengguna masing-masing.
